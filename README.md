# Telegram-воронка курса — MVP

Рабочий бот на Python 3.11+ и aiogram 3. Все шаги воронки открываются только
после нажатия активной Telegram-кнопки. Пользователи, статусы, сегменты,
вопросы и события сохраняются в SQLite.

## Запуск на Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env`, вставьте токен от `@BotFather` в `BOT_TOKEN`, затем:

```powershell
python bot.py
```

## Фото

Положите изображения в папку `images`:

```text
images/IMG_1.JPG
images/IMG_2.PNG
...
images/IMG_10.PNG
```

Также поддерживаются `step_1.jpg`, `1.png` и другие имена с номером шага.
Если фото найдено, бот отправляет по ТЗ три части подряд: **фото** → **текст
карточки** → **короткое сообщение после фото** с активной кнопкой. Если файла
нет, отправляются только текстовые части карточки и follow-up.

## Оплата через ЮKassa (Telegram Payments)

Интеграция идёт через **Telegram Payments**, не через прямой SDK ЮKassa:

```text
BotFather -> PAYMENT_PROVIDER_TOKEN -> send_invoice -> successful_payment -> доступ
```

### Что указать в BotFather

1. Открой `@BotFather` → твой бот → **Payments** → **YooMoney (YooKassa)**.
2. Введи данные магазина:
   - **Shop ID**: `1427327`
   - **Secret Key**: ключ из личного кабинета ЮKassa (`live_...`)
3. Скопируй выданный **provider token** в `.env` → `PAYMENT_PROVIDER_TOKEN`.

### Что указать в личном кабинете ЮKassa

- Магазин должен быть **активирован** и принимать платежи.
- Для чеков 54-ФЗ в `.env` задай `YOOKASSA_TAX_SYSTEM_CODE` (1–6) и `YOOKASSA_VAT_CODE`.
- HTTP-уведомления (webhook) ЮKassa для этой схемы **не нужны** — оплата
  подтверждается через `successful_payment` в Telegram.
- Цена курса: `COURSE_PRICE_KOPECKS=199000` (1 990 ₽).

После оплаты бот автоматически выдаёт доступ (шаг 10) и кнопку перехода к урокам.

Для ручной выдачи доступа менеджером:

```text
/grant TELEGRAM_ID
```

## Канал и вопросы

- `COURSE_URL` — ссылка на закрытый канал или первый урок.
- `ADMIN_IDS` — Telegram ID менеджеров через запятую. Им приходят вопросы.
- Без `ADMIN_IDS` вопросы всё равно сохраняются в таблице `questions`.

Администратор после `/start` видит отдельную кнопку `⚙️ Админ-панель`.
Обычным пользователям она не отправляется. Панель также открывается командой
`/admin` и показывает метрики воронки по статусам из ТЗ, сегменты ответов и
список пользователей с историей событий. Все callback админки повторно
проверяют Telegram ID. В каждом вложенном разделе есть inline-кнопка `⬅️ Назад`.

Вопросы пользователей по-прежнему сохраняются в базе. Ответ менеджера:

```text
/answer НОМЕР текст ответа
```

## Напоминания

Фоновая задача раз в минуту проверяет неоплаченные заказы и отправляет три
сообщения через 3, 24 и 48 часов. Значения задаются в
`REMINDER_DELAYS_HOURS`. Для теста можно поставить `0.02,0.04,0.06`.

База создаётся автоматически в `data/bot.sqlite3`. Таблица `users` содержит
текущий статус и сегмент, а `events` — полную историю прохождения воронки.
